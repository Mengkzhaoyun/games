# 本地 Dota 2

记录这台机器上的 Dota 2 安装位置和游廊相关目录。路径都是绝对路径。

## 1. 游戏本体

| 项          | 值                                                                                   |
| ----------- | ------------------------------------------------------------------------------------ |
| 安装目录    | `C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta`                          |
| Steam 库    | `C:\Program Files (x86)\Steam\steamapps`                                             |
| Steam AppID | `570`                                                                                |
| 运行文件    | `C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta\game\bin\win64\dota2.exe` |

常用子目录：

- 游戏资源：`C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta\game\dota`
- 本地附加地图：`C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta\game\dota_addons`
- 工坊下载：`C:\Program Files (x86)\Steam\steamapps\workshop\content\570`
- 工坊订阅记录：`C:\Program Files (x86)\Steam\steamapps\workshop\appworkshop_570.acf`

Dota 2 的「验证游戏完整性」核对的是本体文件。游廊地图在工坊目录里，不在游戏安装目录里。
