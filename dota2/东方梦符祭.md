## 2. 开局增强

### 2.1 修改目标

只改自己当主机的本地对局，不改付费商店，也不改莉莉白的选卡。莉莉白仍由玩家在开局机制里自己选。

选卡结束后，背包额外得到 5 张角色卡：

- 秋穣子（`item_0003`）：放下后为 **1 星、满培养**（被动升星加速技能 `ability_common_star_up_speed` 升至满级）
- 秋静叶（`item_0088`）：放下后为 **1 星、满培养**（被动升星加速技能 `ability_common_star_up_speed` 升至满级）
- **3 张不重复的随机 1 星 SSR 角色卡**（仅从玩家当局卡池 `towerPlayerList` 中筛选 `quality == 4` 的角色卡，不发卡池之外的卡，放下后为 1 星）

开局金规则调整（原版为基础金 `1500`，难度投票每级再加 `1000`）：

- 修改后基础金为 `10000`，难度投票每级再加 `10000`（即 N1 为 `10000`、N2 为 `20000`、N3 为 `30000`、N4 为 `40000`）。

### 2.2 修改方案

直接修补工坊包 `1332364041.vpk` 内的 `scripts/vscripts/addon_game_mode.lua`，并重算 VPK v2 内部校验链：

1. **开局金币与发卡逻辑**：
   - 原版在 `addon_game_mode.lua` 中通过 `GameRules:SetStartingGold(1500)` 设置基础金，并在 `DOTA_GAMERULES_STATE_STRATEGY_TIME` 阶段通过 `GameRules:SetCustomGameDifficulty(difficulty + 1)` 与 `ModifyGold(..., difficulty * 1000)` 发放难度加成金。
   - 在英雄首次出生（`isFirstSpawn == false`）后，读取当前难度级数 `difficulty = math.max(0, GameRules:GetCustomGameDifficulty() - 1)`，补齐差额金币 `8500 + difficulty * 9000`（使总开局金达到 `10000 + difficulty * 10000`）。
   - 在选卡阶段完成（`_G.g_PlayersCompleteStatus[pid] == 1` 且 `towerPlayerList[pid + 1]` 已生成）后，向背包发放 `item_0003`（秋穣子）、`item_0088`（秋静叶），并从玩家当局卡池 `towerPlayerList[pid + 1]` 中筛选 `item_00*`、`quality == 4`（SSR）且 `count > 0` 的不重复角色卡随机抽取 3 张发放（若从卡池抽取则同步调用 `THTD_RemoveItemInList` 扣减卡池库存并注册售出/吞噬返还监听），初始星级与等级均记为 `1`。
   - 挂钩 `CDOTA_BaseNPC:THTD_InitExp()`：当放下的单位对应上述赠送的秋穣子或秋静叶时，保持 `1` 星不变，并循环调用 `self:THTD_SetAbilityLevelUp()` 将其培养技能升至满级（满培养）；其余 3 张随机 SSR 卡保持原版 `1` 星逻辑。
2. **等长注入与 4 处内部校验同步**：
   - 清理 `addon_game_mode.lua` 中的纯注释行、空行与行首缩进（保留全部 `PrecacheResource` 与原有功能代码），在末尾追加开局增强逻辑并补齐至原长度 `54946` 字节（文件偏移 `943720331`）。
   - 同步更新 `TreeSection` 内 `addon_game_mode.lua` 的 CRC32（偏移 `22572`）、`ArchiveMD5Section` 第 `899` 块的 Blake3-128 摘要（偏移 `1079094367`）、`OtherMD5Section` 中的 `TreeChecksum`（偏移 `1079097995`）与 `ArchiveMD5SectionChecksum`（偏移 `1079098011`）。

本地参考脚本保留在 `C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta\game\dota_addons\touhoutd\scripts\vscripts\utils\copy_config.lua`。
